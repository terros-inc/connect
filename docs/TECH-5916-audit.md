# TECH-5916 Connect API-boundary audit

This records the audit of what this public repository exposes about the Terros
backend: the current tree on `main`, reachable Git commits, PRs #75, #77 and #78
(diffs and discussions), repository tags and releases, and the latest published
`@terros-inc/cli` package. Sensitive values are not copied into this record.

## Scope

TECH-5916 covers the audit and the documentation cleanup only. Code changes it
identified are tracked elsewhere:

- TECH-6104: move the backend-owned logic proposed in PR #75 into `sales`.
- TECH-5687: make the staff versus customer API surface a server-side decision,
  replacing the client-side selection now on `main` (from PR #78).
- TECH-5663: the full-path CLI command redesign that replaces PR #77.
- TECH-5914: customer data in public PR material, and any decision about
  removing it from history.

The generic OpenAPI parser stays in Connect. It reads an injected OpenAPI
document and defines no endpoints of its own.
